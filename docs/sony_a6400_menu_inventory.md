# Inventory of All Original Sony a6400 (ILCE-6400) Menu Items and Their Functions

This document serves as the architectural foundation for building a new, modernized, and optimized user interface (Menu Overhaul) for the Sony a6400.

---

## Tab 1: Camera Settings 1 (Stills Shooting) — 14 Pages

### Page 1/14: Image Quality (Quality / Image Size 1)
1. **File Format:** Select photo format: RAW, RAW & JPEG, or JPEG only.
2. **RAW File Type:** Compressed Sony ARW 14-bit RAW (Compressed).
3. **JPEG Quality:** JPEG compression quality level: Extra fine, Fine, Standard.
4. **JPEG Image Size:** JPEG photo resolution: L (24 MP), M (12 MP), S (6 MP).
5. **Aspect Ratio:** Sensor aspect ratio: 3:2, 16:9, or 1:1.

### Page 2/14: Drive Mode (Shoot Mode / Drive 1)
1. **Drive Mode:** Shutter release mode: Single Shooting, Continuous Shooting (Hi+, Hi, Mid, Lo up to 11 fps), Self-timer, Bracket (Continuous/Single).
2. **Bracket Settings:** Exposure shift configuration for bracketing (step size, shooting order).
3. **Interval Shoot Func.:** Built-in intervalometer for timelapse photography (start time, interval, number of shots, AE tracking).
4. **Memory Recall (MR 1 / MR 2):** Load saved camera settings profiles.
5. **Memory:** Save current camera settings into memory profiles (MR1, MR2, M1–M4).

### Page 3/14: Autofocus 1 (AF 1)
1. **Focus Mode:** Focusing mode: AF-S (Single), AF-A (Automatic), AF-C (Continuous), DMF (Direct Manual Focus), MF (Manual Focus).
2. **Priority Set in AF-S:** Shutter priority in AF-S: AF (only when in focus), Release (fires immediately), Balanced Emphasis.
3. **Priority Set in AF-C:** Shutter priority in AF-C: AF, Release, Balanced Emphasis.
4. **Focus Area:** Autofocus zone: Wide, Zone, Center, Flexible Spot (S/M/L), Expand Flexible Spot, Tracking (Real-time).
5. **Focus Settings:** Quick focus point repositioning using dials.
6. **Switch V/H AF Area:** Remember separate focus point/zone for vertical and horizontal framing.

### Page 4/14: Autofocus 2 (AF 2 - Face and Eye Detection)
1. **AF Illuminator:** Red AF assist light (Auto / Off).
2. **Face/Eye Priority in AF:** Enable automatic face and eye detection in frame.
3. **Face/Eye Subject:** Subject selection for Eye-AF: Human or Animal.
4. **Right/Left Eye Select:** Eye selection for focus: Auto, Right Eye, Left Eye.
5. **Face/Eye Frame Display:** Display frame around detected face/eye (On / Off).
6. **AF w/ Shutter:** Trigger autofocus on shutter half-press (On / Off).

### Page 5/14: Autofocus 3 (AF 3 - Advanced)
1. **Pre-AF:** Focus before the shutter is pressed (Off saves battery).
2. **Eye-Start AF:** Focus as soon as the eye approaches the viewfinder (for A-mount adapters).
3. **AF Area Regist.:** Register a favorite focus point position.
4. **Del. Regist. AF Area:** Delete registered focus point.
5. **Disp. cont. AF area:** Display active AF points in Continuous AF mode.
6. **Phase Detect. Area:** Display phase-detection AF points on the sensor.

### Page 6/14: Exposure 1
1. **Exposure Comp.:** Exposure compensation (+/- 5 EV in 1/3 or 1/2 EV steps).
2. **Reset EV Comp.:** Reset compensation when powering off the camera.
3. **ISO:** Sensitivity setting (ISO 100 to 32000, expandable to 102400) and ISO AUTO.
4. **ISO AUTO Min. SS:** Minimum shutter speed before ISO AUTO starts raising sensitivity (Faster, Fast, Standard, Slow, Slower, or exact speed e.g. 1/250s).
5. **Metering Mode:** Light metering: Multi, Center, Spot (Standard/Large), Entire Screen Avg, Highlight.
6. **Spot Metering Point:** Link spot metering point to focus point (Center / Focus Point Link).

### Page 7/14: Exposure 2
1. **Exposure Step:** Exposure adjustment step: 0.3 EV or 0.5 EV.
2. **AEL w/ Shutter:** Lock exposure on shutter half-press.
3. **Exposure Std. Adjust:** Fine-tune factory light meter calibration for each metering mode.

### Page 8/14: Flash
1. **Flash Mode:** Fill-flash, Slow Sync, Rear Sync, Wireless.
2. **Flash Comp.:** Flash power compensation (+/- 3 EV).
3. **Exp.comp.set:** Whether exposure compensation also affects flash (Ambient only / Ambient & Flash).
4. **Red Eye Reduction:** Reduce red-eye effect with pre-flash.

### Page 9/14: Color, White Balance, and Processing 1
1. **White Balance:** White balance: Auto (AWB), Daylight, Shade, Cloudy, Incandescent, Fluorescent, Flash, Color Temp/Filter, Custom 1-3.
2. **Priority Set in AWB:** Auto WB priority under artificial light: Standard, Ambience (warmer tones), White (pure white).
3. **DRO / Auto HDR:** Dynamic Range Optimizer (D-Range Opt) and automatic HDR for shadow recovery.
4. **Creative Style:** Color profiles: Standard, Vivid, Neutral, Clear, Deep, Light, Portrait, Landscape, Sunset, Night, B/W, Sepia.
5. **Picture Effect:** Artistic effects (Toy Camera, Pop Color, Posterization, Retro, Partial Color, etc.).

### Page 10/14: Color and Picture Profile (PP)
1. **Picture Profile:** Picture profiles (PP1 to PP10) — including Movie, Still, Cine1-4, ITU709, S-Log2, S-Log3, HLG (HLG1-3).
2. **Soft Skin Effect:** Facial skin smoothing effect (Off, Low, Mid, High).

### Page 11/14: Focus Assist
1. **Focus Magnifier:** Digital magnifier for precise manual focusing.
2. **Focus Magnif. Time:** Magnifier display duration (2s, 5s, No Limit).
3. **Initial Focus Mag.:** Initial magnification (1.0x or 5.9x).
4. **AF in Focus Mag.:** Allow autofocus while magnifier is active.
5. **Peaking Setting:** Highlight in-focus edges (Peaking Display On/Off, Peaking Level: High/Mid/Low, Peaking Color: Red/Yellow/White).

### Page 12/14: Shooting Assist
1. **Anti-flicker Shoot.:** Detects fluorescent lighting flicker (100Hz/120Hz) and times the shutter to peak brightness.
2. **Face Registration:** Register priority faces (e.g., bride and groom at a wedding).
3. **Regist. Faces Priority:** Prioritize registered faces during autofocus.

### Page 13/14: Shoot Mode Guide
1. **Shoot Mode Guide:** Display shooting mode description when turning the mode dial.

### Page 14/14: Optical Lens Compensation (Lens Comp.)
1. **Shading Comp.:** Remove vignetting at frame edges.
2. **Chromatic Aberration Comp.:** Remove color fringing (CA).
3. **Distortion Comp.:** Geometric lens distortion correction (Auto / Off).

## Tab 2: Camera Settings 2 (Movie & Custom Operation) — 9 Pages

### Page 1/9: Movie Settings 1 (Movie 1)
1. **Exposure Mode (Movie):** Video exposure mode: Program Auto, Aperture Priority, Shutter Priority, Manual Exposure.
2. **File Format:** Video format: XAVC S 4K, XAVC S HD, AVCHD.
3. **Record Setting:** Resolution and framerate: 4K (24p/25p/30p at 60/100 Mbps), Full HD (24p/25p/50p/60p/100p/120p).
4. **S&Q Settings:** Slow & Quick Motion recording (from 1 fps to 120 fps).
5. **Proxy Recording:** Simultaneous recording of a small 720p proxy video alongside 4K for faster editing on slower computers.

### Page 2/9: Movie Settings 2 (Movie 2 - AF & Audio)
1. **AF Drive Speed:** Focus transition speed in video (Fast, Normal, Slow).
2. **AF Tracking Sens. (Movie):** Subject focus retention sensitivity (Standard, Responsive).
3. **Auto Slow Shutter:** Automatically lower shutter speed below framerate in low light (recommended off).
4. **Audio Recording:** Audio recording: On / Off.
5. **Audio Rec Level:** Fine-tune microphone gain (levels 1 to 31).
6. **Audio Out Timing:** Headphone audio output sync (Live with no delay or Lip Sync with screen).

### Page 3/9: Movie Settings 3 (Markers & Audio)
1. **Wind Noise Reduct.:** Software wind-noise filtering on the microphone.
2. **Micref Level:** External microphone input reference sensitivity (Normal / Low).
3. **Marker Display:** On-screen guide display during recording (On / Off).
4. **Marker Settings:** Marker configuration: Center marker, Aspect marker (e.g., 4:3, 16:9, 2.35:1), Safety Zone, Guideframe.

### Page 4/9: Shutter and Silent Operation (Shutter / Silent)
1. **Silent Shooting:** Completely silent shooting via electronic shutter (no mechanical sound or vibration).
2. **e-Front Curtain Shutter:** Electronic front-curtain shutter (reduces shutter shock).
3. **Release w/o Lens:** Allow shutter release without an electronic lens attached (required for manual and vintage lenses).
4. **Release w/o Card:** Allow shutter release when no SD card is inserted (recommended off for safety).

### Page 5/9: Display and Guides (Display / Auto Review 1)
1. **DISP Button:** Select information modes cycled by the DISP button on screen and viewfinder (Histogram, Level, No Disp, Graphic Display).
2. **Finder/Monitor:** Manual or automatic switching between LCD screen and EVF viewfinder.
3. **Finder Frame Rate:** Viewfinder refresh rate: Standard (60 fps) or High (120 fps for sports/action).
4. **Zebra Setting:** Zebra stripes for exposure control (Zebra Display On/Off, Zebra Level 50 to 100+).
5. **Grid Line:** Screen grids: Rule of 3rds, Square Grid, Diag. + Square Grid, Off.
6. **Exposure Set. Guide:** Visual exposure guide when changing aperture and shutter speed.

### Page 6/9: Live View Display (Display / Auto Review 2)
1. **Live View Display:** Exposure simulation display: Setting Effect ON (shows real brightness and depth of field) or Setting Effect OFF (keeps image bright, e.g., for studio flash work).
2. **Auto Review:** Duration to display captured photo immediately after shooting (10s, 5s, 2s, Off).

### Page 7/9: Custom Operation 1
1. **Custom Key (Shoot.):** Assign functions to physical buttons for stills shooting (C1, C2, AF-ON/AEL, Direction keys, Center button).
2. **Custom Key (Movie):** Separate button assignments for video recording.
3. **Custom Key (Play):** Button assignments during photo playback.
4. **Function Menu Set.:** Customize the **Fn menu** (12 icons displayed on screen).
5. **Dial Setup:** Swap roles of front and rear dials for Aperture / Shutter control.

### Page 8/9: Custom Operation 2
1. **Av/Tv Rotate:** Dial rotation direction for changing aperture and shutter speed.
2. **Dial Ev Comp:** Use dial for direct exposure compensation.
3. **MOVIE Button:** Behavior of the red movie record button: Always or Movie Mode Only.
4. **Lock Operation Parts:** Lock dials by holding the Fn button to prevent accidental setting changes.
5. **Audio Signals:** Audio beeps on focus lock: On / Off.

### Page 9/9: Touch Operation
1. **Touch Operation:** Enable touchscreen (On / Off).
2. **Touch Panel/Pad:** Operation mode: Touch Panel (LCD only) or Touch Pad (swipe screen while looking through the viewfinder).
3. **Touch Pad Settings:** Touch area positioning and absolute/relative finger tracking.

## Tab 3: Network (Wireless Connectivity) — 2 Pages

### Page 1/2: Wireless Transfer
1. **Send to Smartphone Func.:** Send photos to a smartphone (via Imaging Edge / Creators' App).
2. **Send to Computer (Wi-Fi):** Automatic wireless transfer of images to a computer on the same Wi-Fi network.
3. **FTP Transfer Func.:** Background photo transfer to an FTP server.
4. **View on TV:** View images on a Wi-Fi DLNA-compatible TV.
5. **Ctrl w/ Smartphone:** Remote camera control via smartphone screen.
6. **Airplane Mode:** Airplane mode (disables Wi-Fi, Bluetooth, and NFC to save battery).

### Page 2/2: Network Settings
1. **Wi-Fi Settings:** WPS Push, manual Access Point connection (SSID and password), IP address.
2. **Bluetooth Settings:** Pair with Bluetooth devices (e.g., phone for GPS or Sony wireless grip RMT-P1BT).
3. **Location Info. Link Set.:** Retrieve GPS coordinates from phone over Bluetooth and write to EXIF.
4. **Edit Device Name:** Change camera network name (e.g., ILCE-6400).
5. **Reset Network Set.:** Reset all network and Wi-Fi settings.

## Tab 4: Playback — 4 Pages

### Page 1/4: File Management
1. **Protect:** Protect photos from accidental deletion.
2. **Rotate:** Manual rotation of vertical/horizontal photos.
3. **Delete:** Delete photos: single, selected, all in folder, or by date.
4. **Rating:** Rate photos with stars (1 to 5 stars) saved in EXIF.
5. **Rating Set (Custom Key):** Assign rating with a single press of a programmable key.
6. **Specify Printing (DPOF):** Mark images for direct printing on printers.

### Page 2/4: Enlargement and Capture
1. **Photo Capture:** Extract a high-resolution still photo (8 MP) from a paused 4K video.
2. **Enlarge Image:** Zoom into a photo to check sharpness.
3. **Enlarge Initial Mag.:** Initial zoom level (standard or 100% pixel-for-pixel).
4. **Enlarge Initial Pos.:** Initial zoom position (image center or focus point).

### Page 3/4: Viewing Mode
1. **Slide Show:** Automatic image slideshow on screen.
2. **Select PB Media:** Memory slot selection (not applicable since a6400 has one slot).
3. **View Mode:** View by date (Calendar View) or by folder (Folder View for stills/movies).
4. **Image Index:** Matrix thumbnail view (9 or 25 thumbnails on screen).
5. **Display Cont. Shoot Group:** Group burst photos into a single folder for clarity.

### Page 4/4: Screen Display
1. **Rotate Display:** Automatic rotation of vertical images when rotating the camera.
2. **Image Jump Setting:** Configure fast image skipping with the dial (by 10, 100 images, or rated images only).

## Tab 5: Setup (System Settings / Yellow Toolbox) — 7 Pages

### Page 1/7: Brightness and Audio
1. **Monitor Brightness:** LCD brightness: Manual (+/- 2) or Sunny Weather (extra bright for sunny days).
2. **Viewfinder Brightness:** EVF brightness: Auto or Manual.
3. **Finder Color Temp.:** Fine-tune viewfinder color temperature (+/- 2).
4. **Gamma Disp. Assist:** Contrast simulation display for S-Log and HLG profiles (Off, Auto, S-Log2->709, S-Log3->709, HLG->709).
5. **Volume Settings:** Built-in speaker volume during video playback (0 to 7).
6. **Delete Confirm.:** Which option is highlighted first when deleting: "Cancel" (safer) or "Delete" (faster).

### Page 2/7: Power and Regional Mode
1. **Display Quality:** LCD display quality: Standard or High (sharper, uses more battery).
2. **Auto Pwr OFF Temp.:** Thermal shutdown threshold during 4K recording: **Standard** or **High** (extends 4K recording without shutdown).
3. **Pwr Save Start Time:** Inactivity time before entering Sleep mode (10s, 20s, 1min, 2min, 5min, 30min).
4. **NTSC/PAL Selector:** Switch video standard: 24p/30p/60p/120p (NTSC) or 25p/50p/100p (PAL).
5. **Cleaning Mode:** Sensor vibration to shake off dust and shutter lift for manual cleaning.
6. **Touch Sensitivity:** Touchscreen sensitivity: Standard or Sensitive.

### Page 3/7: HDMI and Video Output
1. **Demo Mode:** Retail store demo display on screen.
2. **TC/UB Settings:** Time Code / User Bit settings for professional multi-camera synchronization.
3. **IR Remote:** Infrared remote control receiver (On / Off).
4. **HDMI Settings:**
   - *HDMI Resolution:* Auto, 2160p/1080p, 1080p, 1080i.
   - *24p/60p Output:* HDMI signal framerate.
   - *HDMI Info. Display:* Clean HDMI feed (for streaming/recorder) or display settings on external monitor.
   - *TC Output:* Send Timecode over HDMI.
   - *REC Control:* Trigger recording on an external recorder (Atomos) via camera shutter button.
   - *CTRL FOR HDMI:* CEC control over HDMI cable using a TV remote.
5. **4K Output Select:** Choose whether 4K records internally to SD card or outputs clean 4K only over HDMI.

### Page 4/7: USB and Language
1. **USB Connection:** USB port mode: Auto, Mass Storage, MTP, PC Remote (for Sony Imaging Edge tethering).
2. **USB LUN Setting:** Multi or Single (compatibility with older computers).
3. **USB Power Supply:** Power camera via micro-USB cable during operation (On / Off).
4. **Language:** Interface language selection (factory-locked on region-locked cameras).
5. **Date/Time Setup:** Set clock, date, and daylight saving time.
6. **Area Setting:** Select time zone and home city.

### Page 5/7: Memory and Card Management
1. **Copyright Info:** Write photographer and copyright holder names directly into EXIF metadata.
2. **Format:** Quick format SD card in exFAT / FAT32 format.
3. **File Number:** File numbering: Series (continues sequence) or Reset.
4. **Set File Name:** Change the first three characters of photo filenames (e.g., `A64` instead of `DSC`).
5. **Select REC Folder:** Select folder where new photos are saved.
6. **New Folder:** Create a new folder on the SD card.

### Page 6/7: File System and Version
1. **Folder Name:** Standard folder naming format (Standard or Date Form for date-based folders).
2. **Recover Image DB:** Repair image database on SD card if the camera lost power during recording.
3. **Display Media Info.:** Show remaining SD card space and estimated photo count / video minutes.
4. **Version:** Show firmware version of the camera body and mounted lens.

### Page 7/7: Reset
1. **Setting Reset:** Restore factory defaults: Reset default (shooting settings only) or Initialize (full factory reset).

## Tab 6: My Menu (Star)

Allows the user to organize up to 5 pages of custom shortcuts:
1. **Add Item:** Add any of the above functions to the quick menu.
2. **Sort Item:** Reorder items.
3. **Delete Item:** Remove an individual item.
4. **Delete Page:** Delete an entire shortcut page.
5. **Delete All:** Delete all shortcuts.
6. **Display From My Menu:** Whether pressing MENU opens this tab immediately (On / Off).
