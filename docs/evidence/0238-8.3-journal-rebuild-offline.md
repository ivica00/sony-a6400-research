# E0238 — Journal collector rebuilt with the 8.3 target (offline)

Date: 2026-11-09. Offline only: no camera access, no SD write, no physical session. This applies the E0237 path correction to the bounded journal collector.

## Change

The fixed target was renamed from the rejected `A:/a6400_journal_e0235.dat` to the 8.3-valid `A:/A6400J.DAT` in the ack publisher, the collector's verdict parser, the host runner (`JOURNAL_PATH`), the mocked fixture answers and the path test. Size 64 bytes and initial value `0xE0235000` are unchanged; the expected RAM file still holds eight little-endian u64 words. Probe steps now use `/dev/mmca/A6400J.DAT` and `A:/A6400J.DAT`.
