# E0229 — Bounded passive on-camera collector (offline)

Date: 2026-11-09. No physical device access, mode switch, command publication, cursor change, SD write or UVC activation in this step. E0227 remains the last physical observation.

Implemented `tools/native_camera/native_monitor_collector.c`, linking the E0228 snapshot reader through an explicit embedded entry point. The collector only passes the fixed `--snapshot-output` argument. It polls at one-second intervals for at most61 samples over60seconds, preserving at most one nonempty snapshot. It never acknowledges output, so it neither duplicates repeated snapshots nor claims to prevent output throttling. A quiet window is recorded as captured0, not a successful query.

Its only write targets are a fresh `/tmp_bt/` log and fresh `.receipt`, both opened O_EXCL. The original inode stays open across a potential pathname unlink during an ordinary mode switch. Each snapshot includes the observed cursors and byte count. RAM log fsync failure stops collection. At the end the held inode is copied in bounded chunks to the fresh receipt and each chunk is read back and compared. The total is bounded to32768bytes. Sampling completion says `receipt_pending`; only successful copy verification and final fsync emit `RECEIPT_VERIFIED`. RAM fsync does not establish restart durability. Mode-switch survival itself has not been physically tested for this collector.

Final Sony-libc ARM binary: `artifacts/native/monitor-collector-e0229-receipt/native_monitor_collector.elf`; build command and all input/binary hashes are in that directory's manifest. The reader still contains mutation modes, but this collector calls only its read-only snapshot entry; no arbitrary command argument is accepted by the collector. Repeated embedded calls no longer reconfigure stdio after use.
