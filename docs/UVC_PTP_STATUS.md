## What Comes Next

1. **Aligning Windows Host drivers for composite sub-devices (`usbccgp.sys`)**:
   Since Windows binds `wpdmtp.inf` to `054C:0CAA` when the camera is non-composite, on composite enumeration Windows loads the Generic Parent Driver (`usbccgp.sys`), which creates two children:
   - `USB\VID_054C&PID_0CAA&MI_00` (PTP / WPD)
   - `USB\VID_054C&PID_0CAA&MI_01` (UVC Video)
   It is necessary to ensure session duration (e.g. 60–120 s) and/or associate an appropriate `.inf` so Windows finishes installing both drivers.
